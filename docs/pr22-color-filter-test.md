- Public storefront `/v/cloukuta`: multi-select color dropdown.
- Seller catalog `/catalog`: same multi-select color dropdown.
- Compact closed labels: `Color: Todos` / `Color: All`, one selection `Color: W`, multiple `Color: [W,B,R]`.
