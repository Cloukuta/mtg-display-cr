# Discount promo regression checklist

- Home discounted card: prominent `-XX% OFF` badge is visible over the card.
- Global Catalog single-seller discounted card: same badge is visible.
- Seller Display discounted card: same badge is visible.
- USD face: CK remains labeled as reference and discount state is visible.
- CRC face: reference CRC remains struck through and final CRC remains green.
- Default/custom pricing: no promotional badge is rendered.
- Pricing math, inventory, cart, checkout and orders remain unchanged.
